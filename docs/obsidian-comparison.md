# Obsidian 版与 DSH 版组件能力对照

参照 [乔木 Home 源码](https://github.com/joeseesun/qiaomu-home) 中的 `src/module-library.ts`、`src/pages.ts`、`src/layout.ts` 与 `src/module-catalog.ts`，按 DSH 的宿主能力取舍。

| 能力 | Obsidian 版 | DSH 版 |
| --- | --- | --- |
| 组件库 | 模态弹窗：目标页、搜索、带数量与图标的分类芯片（方向键）、只看未添加、按分类分组、真实内容预览、添加/移除，分类会话内记忆 | 已对齐并增强：同样的弹窗结构；另有「也在哪些 Tab」提示与弹窗内切换目标 Tab |
| 社区组件与插件联动 | 社区目录、依赖检测、安装/启用 | 未移植：DSH 插件模型不同，需先定义安全的组件注册与依赖协议 |
| Tab 栏 | 标签页语义与方向键，`+`、`⋯`、右键菜单、组件库按钮、布置开关 | 已对齐；`←` `→` `Home` `End`，焦点轮换 |
| Tab 菜单 | 组件库、重命名、复制（命名对话框）、前移/后移、删除（确认对话框），主页不可删 | 已对齐；另有「恢复默认布局」，删除可撤销 |
| 新建 Tab | 模板网格（单选、图标、说明），名称跟随模板，空白页建好后自动打开组件库 | 已对齐；模板为 DSH 版的 7 种 |
| 布置模式 | 手柄拖动卡片与 Tab、标记线、边缘自动滚动；点手柄出菜单 | 已对齐；另有 `Alt+↑/↓` 键盘排序与朗读提示 |
| 卡片菜单 | 组件设置、移到其他页、前移/后移、移除 | 已对齐；移除/移动可撤销 |
| 单组件选项 | 显示数量 1–6、各组件专属项（站点、回车行为等） | 已对齐主要项：待办/最近会话/快速记录的显示数量，多站搜索的多选站点与回车行为；其余组件暂无可配置项，菜单里不显示「组件设置」 |
| Masonry 卡片布局（0.7.2） | 不等高卡片各自占行，落进更短的列，DOM 顺序不变 | 已对齐：`masonry.js` 用 ResizeObserver + 1px 行高实现，拖拽与键盘排序不受影响 |
| 天气地点搜索（0.7.x） | 固定城市列表 + 离线中国城市库 + Open-Meteo geocoding 搜索 | 已对齐 geocoding 搜索与中文「市/县/区」变体；离线城市库未移植（体积大），旧版固定城市列表自动迁移为地点 |
| 发现类搜索目录（discovery.ts） | 9 组站点目录（网页/书籍/视频/音乐/AI/论文/词典/翻译/GitHub）+ 自定义模板（`名称 \| URL含{query}`，校验主机与协议） | 已对齐：多站搜索卡片内分组芯片切换、每组独立记住站点选择、翻译组智能目标语言（中文→英，其他→中）、dev 组无查询模板时打开收件页；自定义模板编辑内联在卡片里 |
| 设置迁移 | 持久化的页面与模块状态 | 已将旧版 `hidden` 转为每页组件列表，并为每页新增 `options`；保留原组件数据；旧版天气城市与全局搜索引擎选择自动迁移 |
| Obsidian 笔记组件 | 今日日记、最近修改、随机回顾、Tasks、Dataview（0.9.0）等 | 依赖 Vault 与 Obsidian API，不移植 |
| 快捷入口分组、书签导入 | 多分组（每组一张卡片）、条目编辑与图标、拖拽排序、HTML 书签导入 | 已对齐：分组可新建/重命名/删除/跨页移动，条目可编辑与排序，书签导入（预览、去重、最多 50 个）。不含 Obsidian 特有的笔记/文件夹/命令类入口；旧版自定义网址自动迁入默认组 |
| 原生分栏与主题分隔线（0.8.x） | 主题感知的 pane 分隔线 | DSH 宿主无原生 pane 概念，不适用 |
| 本地壁纸文件夹（0.8.0） | 从 vault 文件夹轮换本地图片 | 未移植：DSH 客户端无宿主文件系统 API；保留 Unsplash 精选 + 渐变 |
| 多语言界面（0.6.0） | 9 种界面语言 + 语言设置 | 未移植：DSH 版跟随宿主语言，提供中英双语 |
| 搜索捕获到每日笔记（0.6.x） | 搜索框输入可存入 daily note | 依赖 Obsidian daily notes，不移植 |
| 组件尺寸、分栏 | Masonry 自适应 | 双列 masonry，窄窗（≤780px）单列；420px 宽下已验证标签栏、芯片与标题排版 |

下一步应优先验证真实 DSH 运行中的组件库、Tab 迁移、窄窗口与键盘交互，再决定插件联动协议。组件安装在此版本指**把已实现组件添加到当前 Tab**，不触发 DSH 的包安装。
